# 严谨

软件工程师基本要求，对于一种表述，用词应该是肯定的；对于定性的描述，应该考虑是否可以提供定量的数据。

# 靠谱

+ 闭环意识：凡事有交代，件件有着落；无论结果如何，到你这里，就应该画上一个句号了。
    + 有头有尾、进展反馈：无论事情简单或者复杂，对于关键节点，应该主动交流反馈，给予对方以掌控感，使其心安。
    + 在能力边界内承诺：人与人之间的信任就是通过一个个小的信任的完成搭建起来的。
    + 上面两点的结合，事情规划和承诺了，但是出现了意外，这是谁也避免不了的，应该及时反馈/上升；调借资源，调整排期，对于风险的及时上报，即使最终延期甚至事情失败了，让对方有心理预期，也能让别人觉得你是靠谱的。

# 价值

在职场初期，通常是被安排做事，这并非是确定的，是可以向上管理沟通的；
应该思考，这件事为什么需要做，是为了达成什么样子的目标，是否一定要使用这样的方法来做？
多思考一些。
