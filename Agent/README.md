# Agent

基于模型（主要是大语言模型）的推理能力为其提供感知和行动能力的一系列应用。

## 上下文有限

 从我的视角看，目前智能体相关的很多工作都是基于这样一个事实——“大模型的上下文有限，注意力有限”；
 假如无限，我们直接将做事可能相关的所有上下文都丢给模型然后试图让模型解答世间一切难题就好了。
